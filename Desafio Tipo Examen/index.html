Ejercicio 1: Raíces de una Ecuación Cuadrática

a) Descripción del problema: Dado un polinomio de segundo grado \(ax^2 + bx + c = 0\), calcular el discriminante \(D = b^2 - 4ac\) y evaluar sus raíces (2 raíces reales, 1 raíz real o sin raíces reales).
b) Algoritmo:
  1. Leer los coeficientes \(a\), \(b\) y \(c\) desde el formulario.
  2. Calcular el discriminante: \(D = (b \times b) - (4 \times a \times c)\).
  3. Si \(D > 0\), calcular \(x_1 = \frac{-b + \sqrt{D}}{2a}\) y \(x_2 = \frac{-b - \sqrt{D}}{2a}\). Mostrar "Dos raíces reales".
  4. Si \(D = 0\), calcular \(x = \frac{-b}{2a}\). Mostrar "Una raíz real".
  5. Si \(D < 0\), mostrar "No tiene raíces reales".

Ejercicio 2: Estimación del Número π mediante Serie

a) Descripción del problema: Aproximar el valor de \(\pi\) utilizando la sumatoria iterativa \(\pi \approx \sqrt{6 \sum_{n=1}^{N} \frac{1}{n^2}}\) mediante un bucle de programación.
b) Algoritmo:
  1. Leer el entero \(N\) suministrado por el usuario.
  2. Inicializar una variable acumuladora suma = 0.
  3. Ejecutar un bucle desde \(i = 1\) hasta \(N\), acumulando \(1 / (i \times i)\).
  4. Calcular la estimación como \(\text{pi\_est} = \sqrt{6 \times \text{suma}}\).
  5. Mostrar el resultado obtenido y comparar contra Math.PI.

Ejercicio 3: La Herencia de los Camellos (Capítulo III)

a) Descripción del problema: Simular el reparto clásico de camellos entre tres hermanos con fracciones \(\frac{1}{2}\), \(\frac{1}{3}\) y \(\frac{1}{9}\), agregando temporalmente un camello prestado para lograr la división entera.
b) Algoritmo:
  1. Obtener la cantidad inicial de camellos \(C\).
  2. Añadir \(1\) camello prestado por Beremiz: \(C_{total} = C + 1\).
  3. Calcular la parte del hermano mayor: \(H_1 = \lfloor C_{total} / 2 \rfloor\).
  4. Calcular la parte del segundo hermano: \(H_2 = \lfloor C_{total} / 3 \rfloor\).
  5. Calcular la parte del hermano menor: \(H_3 = \lfloor C_{total} / 9 \rfloor\).
  6. Calcular los camellos sobrantes: \(\text{Sobran} = C_{total} - (H_1 + H_2 + H_3)\).

Ejercicio 4: El Reparto de los 8 Panes (Capítulo IV)

a) Descripción del problema: Calcular el pago justo de monedas de oro entre dos viajeros que aportan panes para repartir en 3 partes iguales con un tercer viajero.
b) Algoritmo:
  1. Leer el número de panes del viajero A (\(P_a\)), del viajero B (\(P_b\)) y las monedas ofrecidas (\(M\)).
  2. Calcular el total de panes \(P_{total} = P_a + P_b\) y convertir cada pan en 3 tercios: \(T_{total} = P_{total} \times 3\).
  3. Calcular lo que come cada una de las 3 personas: \(T_{persona} = T_{total} / 3\).
  4. Calcular los tercios netos que aporta A (\(A_a = P_a \times 3 - T_{persona}\)) y B (\(A_b = P_b \times 3 - T_{persona}\)).
  5. Distribuir las monedas proporcionalmente a lo aportado.
